# Договорённости проекта

## Общие определения

- `organic`: `is_organic = 1`.
- `recommendation`: `is_organic = 0`.
- `Listen+`: `played_ratio_pct > 50`.
- `active_user`: пользователь хотя бы с одним событием в выбранном периоде.
- `timestamp`: анонимизированная временная шкала с шагом 5 секунд, а не
  календарная дата.

Размер временного бакета команда должна утвердить после изучения распределения
событий. До этого нельзя называть бакеты днями или неделями.

## Правила разработки

1. Одна задача — одна ветка и один pull request.
2. В `main` напрямую не пушим.
3. Минимум один участник проверяет pull request перед объединением.
4. Исходные и производные данные не коммитим; коммитим код их получения.
5. У каждого участника отдельный ноутбук, чтобы избежать конфликтов `.ipynb`.
6. Повторно используемую логику переносим из ноутбуков в `src/`.
7. Для каждой метрики фиксируем формулу, grain, источник и ограничения.
8. Для каждой витрины фиксируем grain, ключ и проверки качества до реализации.
